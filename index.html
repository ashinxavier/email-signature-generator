How to Import Your Signature

📧 Gmail (Web)

  1. Click the Copy HTML button above
  2. Open Gmail and click the gear icon (⚙️) → See all settings
  3. Go to the General tab
  4. Scroll to the Signature section
  5. Click Create new
  6. Press Ctrl+V (or Cmd+V on Mac) to paste
  7. Scroll down and click Save Changes

💻 macOS Mail

  1. Click the Copy HTML button above
  2. Open Mail → Preferences (or Mail → Settings)
  3. Go to the Signatures tab
  4. Select your email account
  5. Click the + button to add a new signature
  6. Press Cmd+V to paste the HTML
  7. Important: Uncheck "Always match my default message font"

📱 iOS Mail

  1. Click the Copy HTML button above
  2. Open Settings → Mail → Signature
  3. Select the email account
  4. Tap in the signature field and paste
  5. Immediately shake your device 📳
  6. Tap Undo when prompted (this retains formatting)
  7. Exit Settings
